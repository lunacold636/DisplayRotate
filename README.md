# DisplayRotate

基于 GY-25T 加速度计的 Windows 屏幕自动旋转工具。C# / WinForms 实现，单文件约 28KB，无需安装任何运行时，Win10 / Win11 直接运行。

把 GY-25T 模块固定在屏幕或支架上，屏幕即可跟随设备姿态自动旋转，适合平板、触控屏、可旋转支架等场景。

## 功能

- 串口扫描与连接（GY-25T，9600 8N1），自动识别并显示 COM 口设备名称
- 多显示器支持：选择要自动旋转的显示器
- 连接后自动旋转：根据传感器姿态在 0°/90°/180°/270° 之间切换
- 开机自启动：写入注册表 Run 项，带 `--autostart` 参数无感启动到系统托盘
- 系统托盘常驻：绿 = 已连接，红 = 未连接，双击托盘图标显示主界面
- 单实例运行：重复启动时提示已运行并退出，避免多份托盘图标与串口争抢
- 自动重连与旋转抑制：断线指数退避重连；旋转后 2 秒抑制窗口防止过渡期抖动振荡
- 托盘「重新校准」：手动改过屏幕方向后一键重建传感器映射
- 运行日志：异常自动写入程序目录 `DisplayRotate.log`，方便排查问题
- 记住上次使用的串口与显示器，下次启动自动恢复连接
- 4K / 高分屏适配（per-monitor DPI 感知 v2）
- 设置保存在 `HKCU\Software\luyanjia\DisplayRotate`

## 工作原理

1. **姿态采集**：GY-25T 模块内置三轴加速度计，通过 UART TTL 串口（9600 8N1）持续上报加速度数据。
2. **协议解析**：模块协议帧以 `0xA4` 开头，末字节为校验和（前面所有字节求和）。程序依次发送初始化指令（查询模式 → 水平模式 → 50Hz 上报 → 读取加速度寄存器 → 自动模式 → 保存设置），随后持续解析 `A4 03 08 06 + X/Y/Z 各 2 字节 + 校验` 的加速度帧。
3. **方向判定**：对最近 20 帧加速度做滑动平均，按 1g 归一化得到重力方向（上/右/下/左）；同一方向连续出现 20 帧才触发旋转，避免抖动误判。
4. **屏幕旋转**：通过 Win32 API（`EnumDisplayDevices` / `EnumDisplaySettingsEx` / `ChangeDisplaySettingsEx`）对指定显示器执行 `DMDO_0 / 90 / 180 / 270` 旋转。
5. **首次校准**：连接后第一次识别到方向时，读取屏幕当前旋转状态，建立「传感器方向 → 屏幕旋转」映射，之后各方向自动对应。

安装方向约定在 `Gy25t.cs` 顶部的 `XUp` / `XDown` 两个常量：默认 X 轴 -1g = 上、+1g = 下；装反了交换两个常量重新编译即可。

## 硬件选型

| 部件 | 型号/规格 | 说明 |
| --- | --- | --- |
| 传感器 | GY-25T 串口角度/加速度模块 | TTL 电平，3.3–5V 供电，本程序只使用其加速度数据 |
| 串口桥接 | USB 转 TTL 模块（CH340 / CP2102 等） | 安装驱动后识别为 COM 口 |
| 连线 | 杜邦线 4 根 | TX/RX 交叉连接，必须共地 |

接线示意：

```
GY-25T              USB-TTL
  VCC  ───────────►  5V / 3.3V
  GND  ───────────►  GND
  TX   ───────────►  RX
  RX   ───────────►  TX
```

> 提示：部分 GY-25T 模块板载稳压与电平转换，可直连 5V；否则请按模块标注使用 3.3V，并保证与串口模块电平一致。

## 代码构建

**方式一（推荐，无需任何开发环境）**：双击 `build.bat`。脚本调用系统自带的 .NET Framework C# 编译器（`csc.exe`）编译源码并内嵌图标资源，产物为当前目录下的 `DisplayRotate.exe`。

**方式二**：用 Visual Studio（或 VS Code + .NET Framework 4.8 开发包）打开 `DisplayRotate.csproj` 构建，目标框架 `net48`。

```
构建产物：DisplayRotate.exe（单文件，约 28KB）
```

## 运行依赖

- Windows 10 / Windows 11（32/64 位均可）
- .NET Framework 4.8（系统自带，无需额外安装）
- USB 转串口驱动（CH340 / CP210x 等，按所用模块安装）
- GY-25T 传感器正确接线并接入电脑

无需安装任何运行时或第三方库。

## 使用说明

1. 运行 `DisplayRotate.exe`
2. 点击「扫描」选择传感器所在串口（如 `COM3  USB-SERIAL CH340`），点「打开」
3. 在「监视器」下拉框选择要自动旋转的显示器（多显示器场景）
4. 连接成功后界面与托盘图标变绿，屏幕随设备姿态自动旋转
5. 勾选「开机自启动」后开机无感运行；点击窗口关闭按钮会最小化到托盘，托盘右键「退出」才真正退出
6. 手动调整过系统屏幕方向后，可在托盘右键菜单点「重新校准」重建映射
7. 运行异常时程序目录下会生成 `DisplayRotate.log`，可据此排查问题

## 常见问题

- **打开失败 / 传感器无响应**：检查 TX/RX 是否交叉、是否共地，确认串口驱动已安装且选择了正确的 COM 口。
- **旋转方向反了**：交换 `Gy25t.cs` 中 `XUp` / `XDown` 两个常量，重新编译。
- **旋转时屏幕短暂黑屏**：显卡驱动切换显示模式的系统级行为，属正常现象。
- **多屏选错显示器**：在「监视器」下拉框选择对应设备即可，设置会自动记住。
